Your library file

Your library lives only in this browser, on this device. Export it to back it up, move it to another phone, or share it. Importing merges, so nothing is overwritten.

Community database

When you scan a barcode that someone else has already added, the title, format and poster are filled in for you. Looking up sends the barcode you scan. Sharing is optional and off by default: if you turn it on, each disc you add with a barcode sends only the barcode, title, format, year and TMDB id. Your library, your notes and the edition field are never sent.

TMDB API key

Needed for title search, posters and years. Free at themoviedb.org (Settings → API → "API Key (v3 auth)"). It's stored only on this device.

This product uses the TMDB API but is not endorsed or certified by TMDB.
